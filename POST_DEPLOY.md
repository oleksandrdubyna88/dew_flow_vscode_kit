Target: the package as GitHub Packages serves it — `@oleksandrdubyna88/vscode-webview-kit`; `$TARGET` is the version just released, without the `v` (for example `<version>`). Run from a checkout of that version's tag: `node .agents/conventions/tools/post-deploy-check.mjs --target <version> --timeout 300000`. GitHub Packages serves nothing without a token, so the commands need `NODE_AUTH_TOKEN` set to a personal access token (classic) with `read:packages`, and a `gh` login that has `read:packages` too (`gh auth refresh -s read:packages`). `release.yml` runs items 1, 2 and 3 in its `publish` job right after it publishes, and item 5 in its `consume` job once `publish` is green, each with the job's own token (item 4 needs `read:packages` on the REST call, so a person runs it); this file is how a person runs all five afterwards and records what they watched.
